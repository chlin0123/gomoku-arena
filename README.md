# 五子棋對弈系統 · gomoku-arena

純前端五子棋對弈系統，不需安裝或建置。**直接雙擊 `index.html` 即可遊玩**（Chrome / Edge / Firefox）。

## 功能
- **人機對弈**：5 位不同程度的 AI 對手，可選執黑、執白或隨機；支援悔棋、提示、認輸，並記錄與每位對手的戰績。
- **雙人對弈**：同一台電腦上兩人輪流對下。
- **打譜研究**：
  - 自由擺棋，退回任一手後重新落子即可試下新變化
  - 每一手都能加註解
  - 逐手瀏覽（← → Home End）、自動播放（空白鍵，可調速度）、顯示手數
  - 「從此局面與 AI 對弈」：用任一局面跟 AI 繼續下
  - 棋譜庫（存在瀏覽器 localStorage）、匯入／匯出 JSON、複製文字棋譜（如 `1.H8 2.I9 …`）

## 規則
無禁手自由規則：黑先，五子或以上連成一線即勝。座標橫向 A–O（左→右），縱向 1–15（下→上）。

## 檔案結構
```
index.html      頁面
css/style.css   樣式
js/ai.js        AI 引擎（棋型表、評估、Alpha-Beta、VCF）
js/app.js       介面、對局流程、打譜與棋譜庫
```
